# 🏟️ Sports Analytics Portfolio

스포츠 데이터를 기반으로 분석 및 간단한 데이터 처리/자동화 로직을 실습한 프로젝트 저장소

## 📁 프로젝트 구조

sports_analytics/
├── baseball/
├── football/
├── nfl/

## ⚾ Baseball

- 데이터 수집 스크립트 (`collector.py`)
- Docker Compose 환경 구성
- CSV / Parquet 데이터 활용

## ⚽ Football

- 플레이어 기반 팀 자동 구성
- 밸런스 고려 분배 로직

## 🏈 NFL

- Jupyter Notebook 기반 데이터 탐색

## 🛠️ 사용 기술

- Python
- Jupyter Notebook
- Docker / Docker Compose
