# 선발투수 원천 조사

이 문서는 `starter_pitchers.csv`를 실제 데이터로 채울 수 있는 외부 원천 후보를 정리합니다. 이번 단계는 원천 조사이며, 선발투수 데이터를 모델 학습이나 사용자용 예측에 적용하지 않습니다.

## 조사 기준

- 기준 날짜: `2026-06-02`
- 대상 경기: `prediction_games.csv`의 해당 날짜 5경기
- 확인 항목: 접근 가능 여부, 홈/원정 팀 확인, 홈/원정 선발투수명 확인, `pitcher_id` 확보 가능성, `game_id` 매칭 가능성, JavaScript 의존성, 수집 리스크

## 원천별 판단

| 원천 | 판단 | 확인 내용 | 주요 blocker |
|---|---|---|---|
| KBO 공식 일정/스코어보드 | 변환 불가 | 페이지 접근은 가능하지만 선발투수 필드를 확인하지 못함 | 공식 일정 HTML에 선발투수 필드 없음 |
| 네이버 스포츠 KBO 일정 | 변환 불가 | 일정 페이지 접근은 가능하지만 초기 HTML에서 기준 날짜 경기와 선발투수명을 안정적으로 확인하지 못함 | JavaScript/API 의존 가능성 |
| 다음 스포츠 KBO 일정 | 부분 후보 | 페이지 접근은 가능하지만 일정 페이지 초기 HTML에서 구조화된 경기별 선발투수 데이터 확인 불가 | 기사/상세 페이지 탐색이 추가로 필요 |
| Statiz 승부예측 페이지 | 수집 후보 | `2026-06-02` 경기별 승부예측 페이지에서 선발투수명과 `p_no`를 확인 가능 | 비공식 HTML 파싱, 이용 조건과 요청 제한 검토 필요 |
| 수동 CSV 입력 | 수동 대안 | `starter_pitchers.csv` 스키마에 사람이 입력하면 검증 가능 | 자동 수집 아님 |

## 추천 원천

1. `Statiz` 승부예측 페이지
   - `2026-06-02` 기준 경기별 선발투수명과 `p_no` 형태의 선수 식별자를 확인할 수 있습니다.
   - 다음 PR에서 날짜별 `s_no` 탐색, 팀명 매칭, 중복 방지, 요청 제한을 포함한 collector 후보로 검증합니다.
2. 수동 CSV 입력
   - 자동 수집이 막힐 경우 운영 fallback으로 사용할 수 있습니다.

## 수집 리스크

- Statiz는 공식 KBO 데이터 원천이 아니므로 HTML 구조 변경 리스크가 있습니다.
- 실제 collector 구현 전 robots.txt, 이용약관, 요청 빈도 제한을 확인해야 합니다.
- 선발투수는 경기 전 변경될 수 있으므로 수집 시각과 원천 URL을 함께 저장해야 합니다.
- `pitcher_id`가 없는 원천은 동명이인 문제가 있으므로 학습 가능 상태로 판단하지 않습니다.
